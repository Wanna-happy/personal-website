# 网站主人配音

**当前状态：系统男声已从网页断开，未使用视频音色生成新台词。HeyGen 已连接、参考音轨已上传，但复刻请求返回 HTTP 402，当前免费套餐不支持此功能。等待账号开通复刻权限，尚未创建音色或生成新配音。以下内容是上一版生成记录。**

2026-09-20 由 Windows Speech Synthesis 的 Microsoft Kangkang 中文男声生成。不是本人声音克隆，也不是新生成的对口型视频。当前作为可替换的讲解配音使用。

覆盖 `narration-scripts.json` 中 5 个章节和 10 个问答，共 32 个完整句子。`manifest.json` 保留逐句文字、文件地址和实际时长。WAV 是原始合成输出；网页按需播放 64 kbps MP3，每句末尾增加 0.28 秒停顿，未加背景音乐。

网页默认关闭声音，点击“开启声音”开始当前句或重新介绍当前页。配音结束才推进字幕。暂停同时暂停声音与动作；下一句中断上一句；切页、跳过、自由浏览或项目弹窗停止讲解。隐藏网页时暂停，返回后继续。音频加载失败则回退到文字计时。

动作在介绍开始及合适的句界触发，结束后稳定等待，不循环短动作。现有动作素材的嘴型未被修改，不能声称与这些台词逐字同步。

复现：先运行 `tools/generate-host-speech.ps1`（需要 Windows 已安装中文男声及语音服务权限），然后 `python tools/package-host-speech.py`。修改文稿后应重新生成音频；网页仅在音频清单文字与当前字幕一致时播放，避免错配旧配音。

验证：`tools/check-host-speech.cjs` 覆盖真实 MP3 播放、字幕推进、暂停和暂停中换句、声音替换、导航与弹窗中断、手机布局和加载失败回退。
