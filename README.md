# 阮涵 · AI 产品作品集（个人网站）

一个**零依赖的纯静态个人网站**，用于展示 AI 产品方向的个人简历与作品集。无需任何构建步骤，浏览器直接打开即可运行。

## 项目结构

```
.
├── index.html        # 页面结构（首页 / 关于 / 经历 / 项目 / 生活 / 联系）
├── styles.css        # 全部样式（暖色纸感主题、响应式布局）
├── script.js         # 交互（自定义光标、滚动揭示、关于区素面→彩色揭示、项目弹窗等）
├── assets/           # 图片资源（首页人像、关于区证件照与素描、生活照）
└── .gitignore        # 忽略本地工具目录与系统文件
```

## 本地预览

任选一种方式：

1. 直接双击 `index.html` 用浏览器打开。
2. 使用本地静态服务器（推荐，避免个别浏览器对本地文件的限制）：

```bash
# 在项目根目录执行
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 关于区交互说明

"关于"区域的证件照默认是**素面素描**，鼠标掠过（或触屏点按）会从光标处圆形揭示出**彩色照片**，移开即恢复素描。若你想让揭示范围更大/更小，调整 `script.js` 中 `mousemove` 事件里的半径数值（当前为 `168`）。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `ruan-han-portfolio`）。
2. 将本项目文件推送上去（不需要 `.tools` 目录，已被 `.gitignore` 忽略）。
3. 仓库 → **Settings → Pages**，Source 选择 **Deploy from a branch**，Branch 选 **main**，目录选 **/ (root)**，保存。
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可，把这个链接分享给别人。

> 提示：资源链接带有 `?v=时间戳` 用于刷新缓存；本地修改后若要强制访客更新，改一下该时间戳即可。

## 内容修改

页面文案（定位、经历、项目、联系方式等）直接编辑 `index.html`；样式在 `styles.css`；交互在 `script.js`。首页头像可在页面内"更换照片"，但持久展示请直接替换 `assets/` 中对应图片。
